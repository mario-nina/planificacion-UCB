# Aplicación virtual — 23/11/2026

Sesión offline del backend de trayectorias. Los pasos virtuales constan como `simulated_complete` en el manifiesto original. No se trata de un ensayo físico.

Se incluyen la gráfica, las muestras y los eventos estructurados de la sesión original. El estado final no demuestra por sí solo la procedencia de todas las muestras; deben interpretarse según los campos de fuente del CSV. El manifiesto íntegro se conserva localmente; `procedencia.json` es un extracto.
