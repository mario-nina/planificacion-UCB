# ABB IRB 120 · ROS 2 Jazzy · RViz

Aplicación académica de cinemática, planificación, supervisión y comunicación RWS/RAPID. El workspace reúne seis paquetes ROS 2 con sus metadatos, recursos y pruebas. Los módulos RAPID y scripts conservan la estructura de rutas del software operativo.

- [Arquitectura](docs/arquitectura.md)
- [Instalación y operación](docs/operacion.md)
- [Modelo y tareas](docs/modelo_y_tareas.md)
- [Validación y referencias](docs/validacion.md)

La reproducción offline utiliza Fedora, Podman rootless y ROS 2 Jazzy sobre Ubuntu Noble. Las credenciales y la configuración particular del controlador se mantienen fuera del repositorio. No se requiere conexión al IRC5 para la modalidad offline.

Las licencias de terceros se conservan en sus respectivos componentes, incluida la licencia ROS-Industrial de las mallas. La operación física está sujeta a los procedimientos y autorización del laboratorio.
